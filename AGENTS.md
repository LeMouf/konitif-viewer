# Repository agent rules

- Do not install or download dependencies without explicit user approval.
- Keep Viewer amodal; renderers, cameras, geometry, physics and product workflows belong to explicit incarnations or hosts.
- Keep `README.md` consumer-facing; contributor, release and agent instructions belong in their dedicated files.
- Build and verify the exact archive before any release operation.
- Do not commit, push, tag or publish without explicit user approval.
